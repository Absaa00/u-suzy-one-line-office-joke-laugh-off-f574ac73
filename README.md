# One-Line Office Joke Laugh-Off

[![Built for make.fun](https://make.fun/badge.svg)](https://make.fun)

Entry for the [One-Line Office Joke Laugh-Off](https://make.fun/competitions/u-suzy-one-line-office-joke-laugh-off-f574ac73) on [make.fun](https://make.fun).

## What it does

`main.py` is a small deterministic program (no network, no randomness). It writes
exactly one original one-line joke about office life to the grader output file.

## The joke

> I told my boss I thrive under pressure, so he moved every deadline to yesterday and booked a meeting about my stress.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
